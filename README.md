# Click to Clean

Citizen app for civic issue reporting (React, TypeScript, Vite, Tailwind). Flow: splash → language → onboarding → phone → OTP → home, report, rewards, and more. Mock data only; no backend.

## Run locally

```bash
npm install
npm run dev
```

## Publish to GitHub (phone / GitHub Pages)

This is a **standalone project**. Step-by-step instructions (new repo, push, Pages, URL) are in **`GITHUB_SETUP.md`** — use that file when you create the GitHub repository and deploy.

## Tech

- React 19, React Router, Motion, react-slick, Lucide, Tailwind v4, exifr (photo GPS)
